Clinical architecture validation
- Direct identifier fields are not part of patient context schema.
- Patient context hash excludes updated_at, preventing false stale invalidation.
- Changing material patient context invalidates stored clinical guidance/review.
- Guidance result must match request_sha256 and country_code.
- Guidance result requires verified_at and at least one source.
- Every applicable guidance/risk/recommendation/conflict claim requires a source_id.
- Clinician review confirmation is Blender UI only; no MCP bridge op can confirm it.
- Medication lookup request transmits medication term only, not patient context.
- Unregistered countries explicitly require live discovery of regulator/dental/maxillofacial/national guidance.
